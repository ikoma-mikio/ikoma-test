==================================================
  履修ワークツリーAI：Claude Code 用ドキュメント
==================================================

このフォルダには、青山学院大学「プロジェクト演習II」の発表課題で使う
MVP企画・実装用ドキュメントを置いています。

もともとの雛形はタスク管理アプリ用でしたが、このプロジェクトでは
「履修ワークツリーAI」に合わせて内容を差し替えています。


【プロジェクトの目的】

青山学院大学社会情報学部の学生が履修登録時に感じる、
「授業同士のつながりが見えにくい」
「研究室や進路に向けた4年間の履修ルートが分からない」
という課題を解決するためのMVPを考えます。

このサービスは、単なる時間割アプリではありません。
授業、研究室、進路、履修条件をワークツリーとして可視化し、
生成AIが学生の目的に合わせて履修ルートを説明するサービスです。


【同梱ファイル】

  1. CLAUDE.md
     Claude Code への指示書です。
     技術スタック、実装方針、AI回答の制約、やってほしくないことを定義します。

  2. SPEC.md
     プロジェクトの仕様書です。
     課題、ターゲット、MVP範囲、機能要件、データモデル、検証方法を定義します。

  3. TASKS.md
     実装・発表準備のタスク管理表です。
     企画整理、データ作成、MVP実装、生成AI連携、検証、発表準備に分けています。

  4. GPT thinking 音声評価.md
     企画案に対する整理・評価メモです。
     発表の方向性やMVPの考え方の参考にします。

  5. 時間割アプリ音声構想.md
     最初のアイデアを書き起こしたメモです。
     課題意識や元の構想を確認するときに使います。


【Claude Code で進める順番】

STEP 1. SPEC.md を確認する
        何を作るのか、MVPでどこまで作るのかを確認します。

STEP 2. TASKS.md を確認する
        今どの作業をするべきかを決めます。

STEP 3. まずはデータを作る
        授業データ、授業間リンク、研究室・進路目標を少量でよいので作ります。
        MVPでは20から30科目程度で十分です。

STEP 4. 画面を作る
        ワークツリー、目標選択、AI相談パネル、4年間プランを1画面で見せます。

STEP 5. 生成AIを組み込む
        最初はモック応答でも構いません。
        重要なのは、登録済み授業データを根拠に説明しているように見えることです。

STEP 6. 検証方法を作る
        アンケート、タスク実験、インタビュー項目を用意します。

STEP 7. 発表資料にまとめる
        10分発表で、課題、解決策、MVP、生成AI、検証方法が伝わるように整理します。


【おすすめのチャット構成】

開発や相談は、3つのチャットに分けて進めるのがおすすめです。

  1. 企画・仕様チャット
     課題設定、ペルソナ、MVP範囲、検証方法、発表ストーリーを整理するためのチャット。
     SPEC.md と TASKS.md を更新する役割です。

  2. MVP実装チャット
     Reactプロトタイプ、授業データ、ワークツリー表示、AI相談パネルを作るためのチャット。
     コード実装に集中する役割です。

  3. 発表・検証チャット
     10分発表スライド、発表原稿、アンケート、インタビュー項目を作るためのチャット。
     授業提出物として見せる形に整える役割です。

1つのチャットに全部入れると、企画、実装、発表準備が混ざって判断しにくくなります。
この3つに分けると、作業の目的がぶれにくくなります。


【アプリ内AIチャットの構成】

アプリ内のAI相談機能は、4つの相談モードで作ると分かりやすいです。

  1. 研究室から探す
     例: データ分析系研究室に行きたい。どの授業を優先すべき？

  2. 進路から探す
     例: IT企業やデータ分析職を目指すなら、何を取るべき？

  3. 授業から調べる
     例: この授業を取る前に、どの授業を取っておくとよい？

  4. 取得済み授業から次を考える
     例: 今ここまで取っている場合、次に取るべき授業は？

MVPでは4つすべてを完璧に作る必要はありません。
発表用には「研究室から探す」または「進路から探す」の1シナリオが動けば十分です。


【最初にClaude Codeへ投げる指示例】

@SPEC.md と @TASKS.md を確認して、まず Phase 1 の授業データ作成から始めてください。
MVP用に、社会情報学部の授業データ、授業間リンク、研究室・進路目標のサンプルJSONを作る方針を提案してください。


【注意点】

楽な授業を探すことを中心にしすぎないでください。
発表では「学習負荷を可視化し、無理のない履修計画を立てる」と表現します。

AIが勝手に履修アドバイスを作る形にしないでください。
先生や学生から整理した授業データ、研究室データ、履修条件データをもとに、
AIが説明する形にします。

MVPで重要なのは、完成度よりも価値検証です。
「この画面を使うと、履修の見通しが立ちやすくなるか」を確認できる形を優先します。
